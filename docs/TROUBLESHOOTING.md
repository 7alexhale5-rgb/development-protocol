# Troubleshooting

| Symptom                                                 | Cause                                      | Fix                                                                                                                                                                                                                                                                                     |
| ------------------------------------------------------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A slash command is not found                            | agent not restarted, or plugin prefix      | restart the agent; with the plugin, try `/development-protocol:<name>`                                                                                                                                                                                                                  |
| `health-check.sh` says a skill is missing               | install targeted the other tool            | `./install.sh --target both`                                                                                                                                                                                                                                                            |
| `WARN ... differs from this repo copy`                  | an older install                           | `git pull && ./install.sh --yes`                                                                                                                                                                                                                                                        |
| `refusing: this repo is inside ...`                     | cloned into the skills folder              | clone elsewhere, then install                                                                                                                                                                                                                                                           |
| `earlier steps are still open`                          | rows pass in order                         | run `status`, pass or n/a the earlier rows                                                                                                                                                                                                                                              |
| `n/a needs a conditional step`                          | that row is always required                | do the row; if the goal words were wrong, restart with `--optional`                                                                                                                                                                                                                     |
| A row passed, then reopened                             | its evidence or an instrument file changed | expected: redo the row against the new file                                                                                                                                                                                                                                             |
| `The verifier changed the evidence`                     | the verifier wrote to the evidence file    | write the evidence first; verify with a read-only command                                                                                                                                                                                                                               |
| `Verifier timed out`                                    | slow suite or a prompt waiting for input   | raise `--timeout`; make the command non-interactive                                                                                                                                                                                                                                     |
| `this step was changed by someone else`                 | two sessions recorded the same row         | re-run the step; give each session its own work item                                                                                                                                                                                                                                    |
| `/ship` cannot read CI                                  | `gh` missing or not logged in              | `gh auth login`, or record the CI link by hand                                                                                                                                                                                                                                          |
| Windows: two agents corrupt a checklist                 | no file lock on Windows                    | one agent per project at a time, or use WSL                                                                                                                                                                                                                                             |
| Worried a secret leaked into `.devproto/<work-id>.json` | a failing verifier printed a credential    | `output_tail` (last 2,000 chars of verifier output) is redacted before writing: known key/token/password shapes become `[REDACTED]`. Review the file before sharing or committing it anyway; redaction is a pattern match, not a guarantee. See `skills/development-protocol/SKILL.md`. |

Still stuck? Try three genuinely different approaches, then ask a teammate with what you tried.
